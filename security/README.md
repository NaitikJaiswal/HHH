## 1. Overview

This module owns the **Security + Blockchain** responsibilities for **HHH (Hash. Hunt. Harden.) / SecureLog**, a blockchain-powered tamper-evident digital forensics platform.

The system ensures that logs generated by distributed infrastructure cannot be altered, injected, deleted, or reordered without immediate cryptographic detection.

```
Log Event ──► LOGN-HASH-v1 ──► Hash Chain ──► Merkle Tree ──► Ed25519 Signature ──► EVM Anchor
```

## 4. Quick Start & Execution Commands

### A. Run Complete Test Suite
```bash
cd security
npm run test:all
```
Executes all unit tests, Hardhat smart contract tests, E2E integration tests, adversarial attack simulations, and performance tests.

### B. Run Interactive Demonstration
```bash
npm run demo
```
Runs an interactive CLI demonstration executing:
1. **Scenario 1**: Valid end-to-end evidence pipeline, Merkle proofs, and blockchain anchoring.
2. **Scenario 2**: Adversarial insider attack, log tampering, and cryptographic detection against on-chain anchor.

### C. Run Performance Benchmarks
```bash
npm run benchmark
```
Measures throughput (operations/sec) and latency (ms) for canonical serialization, hashing, hash chains, and Merkle trees.
