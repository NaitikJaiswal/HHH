# HHH SecureLog - React Frontend (Member 2)

A security-focused, SOC-grade React application for the **HHH (Hash. Hunt. Harden.) – SecureLog Platform**.

---

## 🛡️ Architecture & Responsibilities
- **Branch**: `feature-frontend`
- **Owner**: Member 2
- **Integration**:
  - Connects to **Node/Express Backend** (`feature-backend`) on `http://localhost:5000`
  - Visualizes evidence generated by the **Log Agent & Evidence Engine** (`feature-storage`)
  - Standalone Fallback / Demo Mode: fully interactive even when backend is offline.

---

## 🚀 Key Modules & Pages
1. **SOC Overview Console (`Dashboard.jsx`)**: Ingestion metrics, active collectors, live stream, gap detection watchdog.
2. **Log Explorer & Hunt Console (`LogsExplorer.jsx`)**: Real-time searching, severity filtering, canonical SHA-256 hash inspection, JSON export.
3. **Evidence & Integrity Verifier (`IntegrityVerifier.jsx`)**: Merkle root verification, Ed25519 HSM signature inspection, interactive leaf hash recalculation.
4. **Collector & Heartbeat Monitor (`AgentMonitor.jsx`)**: Live heartbeats, platform adapters (Windows, Linux, App), offline SQLite queue status.
5. **Audit & Compliance Attestation (`AuditCompliance.jsx`)**: SOC 2 Type II, ISO 27001, and HIPAA compliance mapping and cryptographic proof report download.
6. **Authentication & RBAC (`AuthContext.jsx` & `AuthModal.jsx`)**: JWT bearer tokens, role permissions (`admin`, `security_analyst`, `auditor`).

---

## 🛠️ Quick Start

### 1. Install dependencies:
```bash
cd frontend
npm install
```

### 2. Start development server:
```bash
npm run dev
```

App runs by default at `http://localhost:5173`.
